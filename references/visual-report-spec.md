# Visual Report Spec

视觉版是文字日报的派生物，不能删改事实或改变排序。推荐 1080px 宽的单列长图，安全边距 72px，正文最小 28px，标题 44–52px；浅色背景、深色正文，每条 Signal 使用独立卡片。可信度标签采用固定颜色：S 深绿、A 蓝、B 琥珀、C 灰红；Action 使用文字标签，不只依赖颜色。

首屏只放日期、30 秒 Summary 和最多三个核心判断。正文卡片保留标题、可信度、What happened、Why it matters、可选 Product Lens、Action 与短来源名；完整 URL 放在配套 Markdown/网页中，长图可使用编号脚注或二维码。China AI Watch、Builder / Field Signals、Product / Dev Signals 只有有内容时才出现。

导出前检查中文字体嵌入、链接或二维码可用、卡片不跨页截断、颜色对比度、手机端缩放后的可读性，以及视觉版与 Markdown 的标题、数字、等级和排序完全一致。
